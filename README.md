# TinyMCE Editor Image Options

This module provides a "More image options" section to the default Insert image
dialog in TinyMCE. Users can now add other attributes, like CSS styles,
classes, and title.

## Requirements

* [TinyMCE Editor](https://backdropcms.org/project/tinymce)
* At the moment, this module only works with TinyMCE, but it will hopefully
  be able to support other editors (like CKEditor) in the near future.


## Example

* When inserting or editing an image from the editor, the user will now
  see a new "More image options" fieldset, which allows them to enter
  other attributes for the image.
